# OdVC — Odoo Dev

**OdVC** builds custom Odoo Enterprise solutions from Apaneca, El Salvador.
This organization hosts OdVC development work, including a REST API for
transmitting **DTE** (Documentos Tributarios Electrónicos) to El Salvador's
Ministerio de Hacienda electronic invoicing system.

> 🇸🇻 *Soluciones a la medida en Odoo Enterprise y facturación electrónica (DTE) para El Salvador.*

## Projects

- **api-transmisor-dte** *(private)* — Spring Boot API to issue, sign, transmit
  and void DTEs, designed to be consumed by ERPs such as Odoo, SAP or POS systems.
  Currently an academic project (UES, POO135 GT02, Ciclo II 2026) running only
  against Hacienda's test environment.
